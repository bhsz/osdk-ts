ActionForm

Beta — exported from @osdk/react-components/action-form.

Usage​

ActionForm fetches its own action metadata. Wrap your app in OsdkProvider and import the package styles once (see Prerequisites for the @layer order), then pass an action definition — fields, client-side validation, and submission are wired up out of the box. The form title is hidden by default; pass showFormTitle to show it.

Note — @my/osdk is a placeholder for your generated SDK package (e.g. @your-app/sdk). Replace it with the actual package name in your project.

import { updateEmployee } from "@my/osdk";
import { ActionForm } from "@osdk/react-components/action-form";

function UpdateEmployeeForm() {
  return <ActionForm actionDefinition={updateEmployee} />;
}

Style API​

ActionForm is built on BaseForm, so its appearance is driven entirely through --osdk-form-* and --osdk-input-* CSS variables — override them on the form's className (or any ancestor) to restyle without forking the component. ActionForm adds no outer padding by default; apply internal spacing via --osdk-form-content-padding-* and use margin/border/background on a wrapper for card-style framing.

Class names are internal. The form uses CSS Modules, so its class names are hashed at build time and are not part of the public API. Style it by overriding the CSS variables below — the only consumer-facing class name is the one you pass via the className prop. Token defaults live in src/tokens/component-tokens/form.css and src/tokens/component-tokens/input.css; the --osdk-* values they reference are defined in src/tokens/base-tokens/base.css.

Advanced​

ActionForm is the OSDK-aware component most consumers should use. For cases where you need to bring your own data or action metadata, the package also exports the OSDK-agnostic base component, available from @osdk/react-components/action-form.

BaseForm​

BaseForm is the OSDK-agnostic form that renders sections, fields, validation, and a submit footer from primitive props. It carries all of ActionForm's layout and field rendering but does no action-metadata fetching — feed it a formContent array of FormContentItems (standalone fields and sections) and an onSubmit handler. Like ActionFormProps, BaseFormProps is a controlled/uncontrolled discriminated union: for controlled mode provide both formState and onFieldValueChange; for uncontrolled mode omit formState (onFieldValueChange stays optional).
